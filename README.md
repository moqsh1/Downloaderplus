# DownloaderPlus

Paste a YouTube or Instagram Reel link and save the HD video, or just the audio.

## Run

```bash
npm install
npm run dev
```

The app listens on port 8080. `yt-dlp` is downloaded into `bin/` on first start if it is missing.

## Package

GitHub package: `@moqsh1/downloaderplus`

```bash
npm install @moqsh1/downloaderplus --registry https://npm.pkg.github.com
```


TanStack Start, React, Vite, Tailwind.
